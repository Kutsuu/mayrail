# Расписания

Каждый CSV в этой папке может быть отдельным расписанием или отдельным периодом действия.

Чтобы сайт загрузил файл на GitHub Pages, добавь его имя в `manifest.json`:

```json
{
  "files": [
    "routes.csv",
    "summer-2026.csv"
  ]
}
```

Имена CSV могут быть любыми. Период действия берётся из содержимого самого CSV.
